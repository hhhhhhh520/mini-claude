# MCP OAuth 手测指南（连接真实服务）

> 面向读者：想用 mini-claude 连接需要登录的远程 MCP 服务的用户。
> 本指南的每一步都写明"应该看到什么"，照着走即可。发现端点等关键事实
> 于 2026-10-03 实测核对（见文末注记）。

## 这是什么功能

有些远程 MCP 服务需要登录（OAuth）才让用。mini-claude 会在连接时自动
走登录流程：弹出授权网址 → 你在浏览器里点"同意" → 它自动收到回跳并
记住令牌。**只需要登录一次**，之后令牌存在本地，过期还会自动续期。

前置条件：

```bash
pip install -e ".[mcp]"        # 先装 MCP 支持
```

## 第一步：写配置

在 `~/.mini-claude/mcp.json`（或项目 `.mini-claude/mcp.json`）里加：

```json
{
  "mcpServers": {
    "github": { "type": "http", "url": "https://api.githubcopilot.com/mcp", "auth": "oauth" }
  }
}
```

`"auth": "oauth"` 就是打开登录流程的开关。需要指定权限范围时用完整形态：

```json
{ "type": "http", "url": "...", "auth": { "mode": "oauth", "scope": "repo read:user" } }
```

## 第二步：连接（会弹浏览器）

REPL 里输入：

```
/mcp connect github
```

应该看到的顺序：

1. 屏幕打印一条授权网址（`https://github.com/login/oauth/authorize?...`）
2. 浏览器自动/手动打开它，出现服务的授权同意页
3. 点 **Authorize / 同意**
4. 浏览器跳到 `http://127.0.0.1:某端口/callback?...` 并显示"授权完成"
5. 回到终端，显示连接成功；`/mcp` 里该 server 前面是 `[ok]` 并标注
   `（oauth，token 已缓存）`

令牌落盘位置：`~/.mini-claude/mcp-auth/<server名>.json`。删掉这个文件
等于"忘记登录"，下次连接会重新走一遍授权。

## 没有浏览器的环境（SSH / 远程服务器）

默认的本地回跳在"浏览器和终端不在同一台机器"时收不到。改用粘贴模式：

```json
{ "type": "http", "url": "...", "auth": { "mode": "oauth", "callback": "paste" } }
```

流程变成：

1. 终端打印授权网址 → 在**你自己电脑的浏览器**里打开并同意
2. 浏览器最后停留在一个打不开的网址（这是正常的）
3. 把浏览器**地址栏里的完整网址**复制下来，回到终端粘贴、回车
4. 必须是含 `code=` 和 `state=` 的完整网址；只粘一个码是过不了的
   （安全校验要求）

## 日常使用

- **再次连接**：令牌已缓存，直接连上，不会再弹授权
- **令牌过期**：下一次请求前自动用刷新令牌续期，无感
- **查看状态**：`/mcp` 显示每个 server 的 transport、工具数、授权与令牌摘要
- **换账号/重置**：删除 `~/.mini-claude/mcp-auth/<server名>.json` 后重连

## 出问题了怎么办

| 现象 | 原因与处理 |
|---|---|
| 提示"授权失败：access_denied" | 你（或管理员策略）在同意页点了拒绝——重连并点同意 |
| 卡在等待回调后超时 | 回跳没到达本机（远程环境）——改用上面的粘贴模式 |
| 提示回调 URL 缺 state | 粘贴的不是完整网址——重新复制地址栏全部内容 |
| 连接超时（30 秒无进展） | 服务端不可达或网络问题——先确认 url 能访问 |
| 想彻底重来 | 删 `~/.mini-claude/mcp-auth/` 下对应文件，重连 |

## 手测清单（对照打勾）

- [ ] 首次连接：打印授权网址 → 浏览器同意 → 自动回跳 → 连接成功
- [ ] `/mcp` 显示 `（oauth，token 已缓存）`
- [ ] 断开重连（`/mcp disconnect` + `connect`）：不弹授权直接连上
- [ ] 连接后调用一个该 server 的工具（首次会请求确认，回复 yes）
- [ ] 在同意页点拒绝：连接失败且错误信息写明 access_denied，不崩
- [ ] 粘贴模式（callback:"paste"）：粘贴完整回跳网址后连接成功
- [ ] 只粘贴裸 code：得到"缺少 state"的明确报错
